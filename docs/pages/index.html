NINA plugin repository

See plugins for NINA

A combined home for the SeeDew, SeeDark, SeeDither, and SeeDrift plugins — each one built to make a Seestar telescope a little easier to run in NINA.

Plugin repository URL
https://cstovi.github.io/NINA_SeePlugins
NINA 3.x Seestar Free & open source

Add the repository in NINA

  1. 1

    Open Options in NINA

  2. 2

    Go to General

  3. 3

    Open Plugin Repositories

  4. 4

    Press Add and paste the URL above

Once added, the plugins appear in the Plugins list for you to install and enable.

The plugins

SeeDew

Automatically turns the Seestar dew heater on and off based on the temperature/dew point margin.

SeeDark

Captures master darks only when needed, and stacks median masters from raw darks.

SeeDither

Absolute GoTo coordinate-offset dithering for Seestar S30/S50 mounts — no guider required.

View on GitHub →

SeeDrift

Drift analysis for Seestar devices using NINA session logs, with an interactive HTML report.

Existing manual installs

Switching to this repository should not remove your plugin settings. The See plugins store settings outside the plugin install folder, under %LOCALAPPDATA%\NINA\SeeDew, SeeDark, SeeDither, and SeeDrift.

If you previously copied DLLs manually, NINA should recognize matching plugins by their plugin GUID and show them as installed or updateable. If you ever see duplicates, remove only the old manual plugin DLL/folder under %LOCALAPPDATA%\NINA\Plugins\3.0.0. Do not delete the separate settings folders unless you intentionally want to reset configuration.
